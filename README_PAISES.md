# Monitor por países

La portada index.html permite elegir país. El monitor de España está en espana.html y conserva su plantilla y datos. México, Turquía, Argentina, Colombia, Perú y Venezuela tienen una página provisional, sin datos. Los enlaces antiguos con secciones en el fragmento se redirigen a España.

El proceso build_page.py regenera espana.html y artifact.html sin alterar la portada. El flujo automático incorpora espana.html al publicar datos. Antes de subir, compare con la versión actual del repositorio.
